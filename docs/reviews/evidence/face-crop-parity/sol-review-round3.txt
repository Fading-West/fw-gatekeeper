Blocking findings and fixes:
- bounded_json.py's default ijson yajl2_c parsing segfaulted (return code -11)
  on an authenticated JSON body with a 5,000-digit integer in an ignored field.
  An extreme exponent also raised uncaught decimal.InvalidOperation (HTTP 500).
  Parse using use_float=True instead: native numeric overflow returns a parser
  error, mapped to 422. ArithmeticError is caught for backend conversion errors.
  Finite normalized 512-dimensional vectors do not need arbitrary precision.
- Non-object roots bypassed the generic array counter because ijson uses
  "item", not ".item", for root arrays. These are invalid API requests anyway;
  reject the first non-map event before allocating/echoing a large invalid root.
- Add subprocess regression coverage for numeric attacks on both C and pure
  Python backends, plus six-photo/full-roster boundaries, nested arrays, event
  caps, escaped keys, Unicode string lengths and malformed UTF-8.
