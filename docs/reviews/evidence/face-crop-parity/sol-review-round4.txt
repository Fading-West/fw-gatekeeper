Independent GPT-6.1-Sol recheck, round 4; starting head ddead94.

Blocking findings and minimal fixes:
- bounded_json.py: ijson.parse batches prefixed events for an entire 64 KiB
  chunk before the depth/key guards can run. A 30 KB object containing 15,000
  nested array starts peaked at 580.6 MiB native / 750.7 MiB Python, exceeding
  the Render limit before returning 422. Use ijson.basic_parse and construct
  bounded tuple paths only as events pass the guards. The same payload now
  peaks at 43.9 / 41.6 MiB; a subprocess regression imposes a 128 MiB address
  limit and requires peak RSS below 100 MiB on both backends. Empty/dotted keys
  cannot bypass array counts or impersonate known schema paths.
- YAJL substitutes some lone high surrogate escapes, whereas Python JSON
  preserves them. An invalid worker_id list or missing worker_id with such a
  key passed preflight and caused UnicodeEncodeError in FastAPI's validation
  response (HTTP 500). Reject unpaired surrogate escapes in raw body bytes,
  respecting escaped backslashes and valid adjacent pairs. Both backends now
  return 422 before FastAPI parsing, while valid Unicode worker IDs round-trip.

Parser and whole-PR checks:
- Float mode still rejects 5,000-digit integers and overflowing exponents on
  both backends. Native float callbacks use checked PyLong_FromLongLong and
  PyFloat_FromDouble; string/key conversions check failures. The unchecked
  PyLong_FromString path is confined to non-float mode, which is not used.
- Preflight is deliberately stricter than Python JSON for NaN/Infinity,
  BOM/UTF-16, unpaired surrogates, overflowing numbers and non-object roots.
  Both reject trailing data. Duplicate keys are accepted and every occurrence
  counts toward limits; Python's last-key-wins decoding stays bounded. Finite
  long decimal mantissas and extreme negative exponents parse safely in both.

  wheel. Its compiled yajl2_c backend is first in ijson's default selection;
  local identical pinned packages select it. Pure-Python fallback is covered

- Repeated rejection (20 requests) with deep arrays, oversized strings or
  oversized keys showed stable RSS on both backends. Iterator basic events

- Admission reservations release after structural/Unicode, schema, decode,

  Authentication and actual-byte admission remain ahead of body parsing.
